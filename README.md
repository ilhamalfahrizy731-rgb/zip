## ✨ Features

### 🎮 Interactive 3D Model
- **Real-time 3D visualization** with Three.js
- **Drag to rotate** the Lamborghini model
- **Toggle wireframe** mode to inspect structural geometry
- **Auto-rotate** with hover pause

### 🎬 Cinematic Hero Section
- **Image sequence scrubbing** (116 frames)
- **Scroll-triggered animations** with GSAP
- Dynamic text transitions as you scroll

### 🔊 Engine Sound Simulator
- **Interactive RPM telemetry** with live visual feedback
- **Sound equalizer** animation
- **Rev engine button** with realistic RPM simulation (up to 8,250 RPM)

### 🎨 Ad Personam Color Studio
- **10 iconic Lamborghini colors** to choose from
- **Live color preview** with glow effects
- **Bespoke craftsmanship** information

### 🚀 Performance Metrics
- **4 key performance indicators**: Power, Torque, Weight, Gear Shift
- **Glass-morphism UI** with 3D hover effects
- **Smooth animations** with GSAP

### 🎯 Interactive UI
- **Premium glass-morphism design**
- **Particle background** effects
- **Responsive design** for all devices
- **Smooth scroll** navigation

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **[Three.js](https://threejs.org/)** | 3D model rendering & interaction |
| **[GSAP](https://greensock.com/gsap/)** | Scroll animations & transitions |
| **[TailwindCSS](https://tailwindcss.com/)** | Styling & responsive design |
| **[GLTFLoader](https://threejs.org/docs/#examples/en/loaders/GLTFLoader)** | 3D model loading (.glb) |
| **[VanillaTilt](https://micku7zu.github.io/vanilla-tilt.js/)** | 3D card hover effects |
| **[OrbitControls](https://threejs.org/docs/#examples/en/controls/OrbitControls)** | 3D model rotation controls |
